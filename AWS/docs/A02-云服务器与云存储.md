# 02-云服务器与云存储

## 云服务器EC2的属性

- **Amazon Elastic Compute Cloud(Amazon EC2) EC2 实例 (EC2 Instance)**：EC2 是 AWS 提供的一种计算服务，它以 EC2 实例的形式存在，因此一个 EC2 实例可以被认为是一个**虚拟机**。
- **系统镜像 (AMI)**：预配置的 EC2 镜像被称之为 **Amazon Machine Images (AMI)**，一个 AMI 包含了用户打包好的**操作系统**，以及相应的**应用程序和配置**。
- **实例类型 (Instance Types)**：不同的 EC2 实例类型包含了不同的 **CPU、内存、存储和网络性能**，由**类型、代别、实例大小**三个维度组成。
- **访问方式 (Key Pair)**：AWS 默认以及建议使用**密钥对 (Key Pair)** 的形式访问 EC2 实例，AWS 将保存公钥，用户负责保存**私钥**。
- **短暂性存储 (Instance Store)**：**EC2 实例存储 (Instance store volumes)** 是一种短暂性的存储。一旦停止或者终止 EC2 实例，该存储内的数据将**永久消失**，但重启实例时数据不会消失。
- **持续性存储 (EBS)**：**EBS 存储 (Amazon EBS volumes)** 是一种持续性的存储。不管 EC2 实例处于什么状态，都可以保留 EBS 存储内的数据。这种类型的存储对于进行**数据盘的迁移**非常方便，使用场景也比较多。
- **防火墙安全组 (Security Group)**：安全组会通过检测数据包的**端口、协议、源 IP 地址**，从而充当**防火墙**的作用。
- **公网 IP (Public IP)**：提供**不固定的公网 IP**，每次关机重启该地址可能会发生改变。
- **弹性 IP (Elastic IP address)**：可以方便用户为 EC2 实例分配一个**固定的公网 IP 地址**，并且保证每次关机重启该地址依旧有效。
- **虚拟私有云 (VPC)**：**Virtual Private Cloud (VPC)** 是 AWS 的网络组件，可以让用户的 AWS 资源与其他用户的资源在**逻辑上进行隔离**。用户也可以使用 VPC 与其**物理数据中心**进行连接。

## 云服务器EC2实例类型

- On-Demand Instances，按需实例
- Reserved Instances，预留实例，包年包月

## 云服务器EC2的性能类型

- **通用型**：提供计算、内存、联网资源三方面的平衡，适用于不同的工作负载。
- **计算优化型**：适用于高性能处理器获取的计算限制应用程序，必须媒体转码、高性能web服务器，高性能计算、科学建模、专用游戏服务器、机器学习等。
- **内存优化型**：提高处理内存中大型数据集中的工作负载的性能。
- **加速计算型**：使用硬件加速器或协同处理器进行浮点运算、图形运算等，比在CPU上运行软件更高效。
- **存储优化型**：对本地存储上的大型数据集进行高速连续读写访问的工作负载。

## 云服务器EC2归纳总结

- **云虚拟机**：基于计算存储分离的架构进行构建，构建时由**地域、机型、操作系统、存储、网络**等多方面选项共同构成；**网络安全组**是保护云虚拟机的云端防火墙，可以同时应用于多个虚拟机。
- **云虚拟机的配置规格**主要由**类型、代别、实例**大小维度组成。
- **虚拟机的规格**直接决定了虚拟机的计算能力和特点，**规格**和**模式**直接影响使用成本。
- **虚拟机的类型**，指具有同一类设计目的或性能特点的虚拟机类别；云厂商会提供**通用均衡型、计算密集型、内存优化型、图形计算型**等常见的虚拟机类型。
  - **通用均衡型**：通用均衡型的 vCPU 和内存比例通常是 **1:4**，如 2 核 8G，适用于常规建站、应用服务器等各种普遍性的工作，例如作为企业官网及应用的后端服务器等。
  - **计算密集型**：比是 **1:2**、**1:1**（但通常 1:1 较少），它一般用于进行科学计算、视频流处理，格式转换编码、代码编译等类似工作。
  - **内存优化型**：比例为 **1:8 及以上**，如 16 核 128G 的搭配，它常见于大数据分析中。
- **云虚拟机定价模式**：
  - **按需实例**：借助按需实例，我们可以根据运行的实例以按小时或按秒的方式为计算容量付费。
  - **预留实例**：的付费方式是最常见的降低虚拟机使用成本的方法，它通过牺牲采购的灵活性来换取折扣。
  - **竞价实例**：的机制让云端的闲置资源对外开放，基于市场竞拍的定价方式，常常能够让我们获得很大的折扣。这种方法主要是通过牺牲稳定性，来换取成本上的节约。
- **云硬盘**：云虚拟机上挂载的硬盘，分为系统盘和数据盘，如 AWS 中的 **EBS**。
- **云虚拟机还附加了很多“零件”**：如 **EIP**，**安全组**等。

# 云存储

## **EBS(Amazon Elastic Block Store)**

- 高性能数据块存储服务，适用于任何规模的吞吐量和事务密集型工作负载。
- 归属于服务器里的硬盘资源，服务器没了，服务器里的数据也就没了。
- **使用场景**：灾难恢复（Disaster Recovery）、数据迁移（Data Migration）、快照备份（Backup Compliance）
- **优势**：任意工作负载都能高效使用；**可用性强，持久性强；安全；经济高效。**
- **卷类型**：
  - **SSD型卷：**io2、io1、gp2（默认gp2）
  - **HDD型卷**
    - st1：适用于频繁访问，大型数据集和IO密集型工作负载
    - sc1：低成本，适用于非频繁访问，且据拥有大型冷数据集的工作负载。
- **实例存储**：
  - 提供临时性块级存储，附加在主机的磁盘上，如果主机到期结束，实例存储的数据也就没有了。
  - 修改实例类型，实例存储不会被附加到新的实例类型。
