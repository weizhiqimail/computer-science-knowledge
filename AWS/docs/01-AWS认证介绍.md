# 认证级别

- 内容：学习 AWS 云基础知识和核心概念。无需具备相关经验。
- 考试时长 90 分钟，65 道单选题或多选题，费用为 100 美元。（其中15题不计分，但是不会被标注出来）

- [AWS Certified Cloud Practitioner（CLF）](https://aws.amazon.com/cn/certification/certified-cloud-practitioner/)
  - 展示 AWS 云服务、云计算、基础安全、计费与成本等方面的基础知识。

- [AWS Certified AI Practitioner（AIF）](https://aws.amazon.com/cn/certification/certified-ai-practitioner/)
  - 验证 AI、机器学习、生成式 AI 以及 AWS AI 服务方面的基础知识。

- [AWS Certified Machine Learning Engineer – Associate（MLA）](https://aws.amazon.com/cn/certification/certified-machine-learning-engineer-associate/)
  - 验证在 AWS 上构建、部署和维护机器学习解决方案所需的工程能力，主要面向 ML Engineer。

- [AWS Certified Solutions Architect – Associate（SAA）](https://aws.amazon.com/cn/certification/certified-solutions-architect-associate/)
  - 验证使用 AWS 服务设计安全、高可用、高性能和成本优化架构的能力。

- [AWS Certified Data Engineer – Associate（DEA）](https://aws.amazon.com/cn/certification/certified-data-engineer-associate/)
  - 验证数据采集、转换、数据模型设计、数据生命周期管理和数据质量等能力。

- [AWS Certified Developer – Associate（DVA）](https://aws.amazon.com/cn/certification/certified-developer-associate/)
  - 验证开发、测试、部署和调试 AWS 云应用程序的技术能力，主要面向开发人员。

- [AWS Certified CloudOps Engineer – Associate（SOA）](https://aws.amazon.com/cn/certification/certified-cloudops-engineer-associate/)
  - 验证在 AWS 上部署、管理、监控、维护和操作工作负载的能力，偏云运维。

- [AWS Certified DevOps Engineer – Professional（DOP）](https://aws.amazon.com/cn/certification/certified-devops-engineer-professional/)
  - 验证 CI/CD、基础设施自动化、监控、事件响应以及开发与运维整合方面的高级能力。

- [AWS Certified Solutions Architect – Professional（SAP）](https://aws.amazon.com/cn/certification/certified-solutions-architect-professional/)
  - 验证设计复杂、大规模、高可用、安全且成本优化的 AWS 云架构的高级能力。

- [AWS Certified Generative AI Developer – Professional（AIP）](https://aws.amazon.com/cn/certification/certified-generative-ai-developer-professional/)
  - 验证使用 Amazon Bedrock 等 AWS 服务构建和部署生产级生成式 AI 应用的高级能力。

- [AWS Certified Machine Learning – Specialty（MLS）](https://aws.amazon.com/cn/certification/certified-machine-learning-specialty/)
  - 验证在 AWS 上构建、训练、调优和部署机器学习模型的专业能力。

- [AWS Certified Advanced Networking – Specialty（ANS）](https://aws.amazon.com/cn/certification/certified-advanced-networking-specialty/)
  - 验证设计、实施和维护复杂 AWS 网络及混合云网络架构的高级能力。

- [AWS Certified Security – Specialty（SCS）](https://aws.amazon.com/cn/certification/certified-security-specialty/)
  - 验证 AWS 数据、工作负载、身份权限、基础设施和云架构安全方面的专业能力。
